# Rock-Paper-Scissor

This is my Rock Paper Scissors game made as part of The Odin Project Foundations course. I built it using JavaScript to practice writing functions and working with user input.

## How to play

1. Open the webpage in your browser.
2. Open the browser console to see the game results.
3. Enter `rock`, `paper`, or `scissors` when prompted.
4. Play 5 rounds against the computer.
5. Check the final score to see who won.

## Rules

- Rock beats scissors.
- Scissors beats paper.
- Paper beats rock.
- Choosing the same option results in a tie.

## What I learned

- Writing JavaScript functions
- Using `Math.random()` to generate random choices
- Getting user input with `prompt()`
- Using conditional statements
- Working with function parameters and return values
- Using loops to repeat a task
- Keeping track of scores with variables
- Using `console.log()` to display results
